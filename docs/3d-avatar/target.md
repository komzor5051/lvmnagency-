# Финальный результат — 3D-аватар на сайте

Что мы в итоге должны получить. Это определение «готово», не инструкция.

## 1. Сам ассет (3D-модель)

- **Формат:** glTF binary — один файл `.glb`.
- **Что внутри:** одна модель — голова + плечи (бюст) Влада, замкнутая со всех
  сторон (для полного оборота 360°, чтобы затылок и профиль существовали).
- **Полигонаж:** ~15–40k треугольников. Достаточно для гладкой формы, но лёгкий
  для веба и мобилок.
- **Вес файла:** цель < 2–3 МБ (иначе долго грузится на слабом интернете).
- **Материал:** приходит как есть, но на сайте я перекрашиваю в свой —
  матовый монохром (графит/чернильный) + один лаймовый контурный свет.
  Текстура кожи/цвет из генерации не нужны, важна только форма (геометрия).
- **Ориентация:** голова по центру, смотрит вперёд, вертикально — чтобы
  вращалась вокруг своей оси без смещения.

Итоговый файл лежит в проекте как `public/avatar.glb`.

## 2. Как это живёт на сайте (сцены)

Одна и та же голова видна на всём сайте (один WebGL-холст на фоне), и при
скролле она вращается и переезжает. Контент секций выстраивается вокруг неё.
Черновая раскадровка по существующим главам:

| Секция | Что делает голова |
|---|---|
| **Hero** (первый экран) | Крупно справа, медленно доворачивается 3/4 → фас, лёгкое покачивание. Знакомство. |
| **Numbers** (цифры) | Уезжает вбок/уменьшается, освобождает место под цифры, продолжает медленный оборот. |
| **Manifesto** | Проворачивается в профиль, уходит на второй план (полупрозрачность/монохром), текст ведёт. |
| **Method** (Аудит→Сборка→Масштаб) | Ключевая сцена: голова делает основной оборот 360° по мере прохождения 3 шагов, лайм-акцент усиливается к «Масштабу». |
| **Cases** | Смещается, работает как якорь-фон, доворот в такт карточкам. |
| **Entries / About** | Возврат к фасу, крупный план для личного блока. |
| **Final (CTA)** | Голова в центре/анфас, лайм-подсветка на максимуме — финальный акцент под кнопку. |

Точные углы, позиции и тайминги пропишем отдельным дизайн-документом, когда
будет модель — на ней проще калибровать. Сейчас это ориентир.

## 3. Поведение и техника (делаю я)

- **Стек:** three.js + react-three-fiber, вращение привязано к прогрессу скролла.
- **Один холст** на весь сайт (голова не перезагружается между секциями).
- **Деградация:** на мобильных / при reduced-motion — либо статичный кадр головы,
  либо плоское фото, без WebGL. Сайт должен оставаться быстрым.
- **Перф-бюджет:** 60 fps на десктопе, без рывков и layout shift.
