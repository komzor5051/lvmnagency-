# Редизайн vladlyamin.ru — «Poster / HUD» (полный сайт)

Дата: 2026-07-04. Статус: утверждён Владом по секциям (визуальный брейншторм, макеты в `.superpowers/brainstorm/80492-1783171384/content/`).

## 1. Суть

Полный редизайн всех страниц сайта в эстетике Awwwards-референсов (jasonbergh.com, ilcapoproduction.com, nfinitepaper.com, sanrita.ca и др.): постер-типографика, фиксированная HUD-рамка, чередование светлых и тёмных глав, smooth scroll, переходы-шторки. Текущий концепт главной «signal from noise» (частицы, halftone-портрет, `components/home/engine`) полностью заменяется и удаляется.

Вау-эффект работает на продажу: анимации — доказательство уровня, но воронка (гайд → консультация → аудит → внедрение) и CTA остаются главными. Ничего, что мешает конверсии.

## 2. Позиционирование и копирайт

Новый фрейм (слова Влада): **«Помогаю фаундерам строить и масштабировать системы с помощью AI»**. Фрейм «второй мозг» упразднён — вычистить из всех страниц и из `lib/lvmn-features.ts` (источник правды для блог-пайплайна).

Правила текста:
- Ни одного упоминания стека (n8n, Claude, Supabase, RAG, Apify и т.п.) в видимом тексте. Кейсы называются результатом, не технологией.
- Без паттернов AI-слопа: никаких «Я не X, я Y», негативных параллелизмов, правила трёх, бегущих строк-маркиз. Весь новый текст проходит через humanizer.
- Негатив-триада «Не агентство / Не очередной курс / Не разовый проект» — сохраняется (одобрена отдельно).
- Ключевые утверждённые тексты:
  - Hero: «Помогаю фаундерам строить и масштабировать системы с помощью AI» + саб «Разбираю, где бизнес держится на ручном труде, и собираю вместо этого систему. Она работает, пока вы занимаетесь ростом.» + рукописная пометка «строится 2 недели, работает годами →»
  - Манифест: «Бизнес растёт до точки, где всё завязано на основателе. Дальше либо нанимать, либо строить систему.»
  - Обо мне (тизер): «Каждую систему собираю сам.» / «От первого созвона до передачи. Вы общаетесь со мной, а не с менеджером.»
  - Финал: «Готовы строить систему?»
- Цифры proof-блока (17 систем / 60 ч/мес / 2 недели) — плейсхолдеры, уточнить у Влада перед публикацией.

## 3. Дизайн-система

Основа — эволюция White + Lime (`app/globals.css` `@theme`), радиус 0, теней нет, без эмодзи.

**Цвет.** Светлые главы: `#FFFFFF` / `#F7F6F3`, чернила `#111111`, muted `#666666`, линии `#E8E8E8`. Тёмные главы: фон `#0C0C0C`, текст `#EDEDE8`, muted `#8A8A84`, линии `#262626`. Лайм `#C8F04C` (на светлом для линий/обводок — `#A8D030`) — единственный акцент. Страницы чередуют светлые и тёмные главы; фон меняется плавной заливкой при скролле (GSAP анимирует фон контейнера).

**Типографика** (все — кириллица, через next/font):
- Display: **Literata** 250–300 (заголовки, clamp 40px → 110–130px, letter-spacing −0.02…−0.03em, line-height ~0.98). Курсивные вставки для акцентных слов. Приём «ghost»: контурный текст (`-webkit-text-stroke`, прозрачная заливка) для неактивных/вторичных слов.
- Body/UI: **Inter Tight** + **Onest** (как сейчас).
- Mono: **JetBrains Mono** — HUD, нумерация, метаданные, подписи. Размер 10–11px, letter-spacing .08em, uppercase.
- Рукописный: **Marck Script** — акцентные слова, пометки на полях (поворот −2…−3°), подпись «Влад Лямин».

**Рукописный SVG-слой.** Обводка-эллипс вокруг ключевых слов («системы») и волнистое подчёркивание. Правила: обводка сидит НИЖЕ оптического центра слова (top ≈ 14%, высота ≈ 118%) и ВСЕГДА за текстом (`isolation: isolate` на спане, `z-index: -1` на svg). Лаймовый маркер-заливка (`.hl`) — псевдоэлемент за текстом, покрывает только нижние ~2/3 строки (top 0.18em), чтобы не наезжать на строку выше. Линии отрисовываются анимацией (stroke-dashoffset) при попадании во вьюпорт.

## 4. HUD-рамка (ядро сайта)

Фиксированный слой поверх всех страниц (`position: fixed`, pointer-events: none, кроме интерактивных зон):
- Углы, JetBrains Mono 11px: слева сверху — название текущей главы/раздела; справа сверху — порядковый номер `02 / 08`; слева снизу — «Влад Лямин»; справа снизу — «@lyaminvl» (кликабельно).
- Сверху по центру — порядковые полоски прогресса (по числу глав страницы), заполняются лаймом по мере прохождения.
- HUD меняет цвет под фоном: светлый текст на тёмных главах, чёрный на светлых (IntersectionObserver / ScrollTrigger).
- Наполнение по страницам: главная — главы 01–08; /audit — шаги 1–7 (+ «≈ N минут» в углу); /blog — раздел и дата; /products/[slug] — номер продукта.
- HUD — это и навигация: клик по номеру/полоскам открывает полноэкранное оглавление глав (fullscreen overlay-меню, тёмное, пункты — постер-строками с нумерацией). Обычное меню (лого + бургер) живёт в том же слое.

## 5. Моушн-язык

- **Lenis** smooth scroll глобально. Главы — полноэкранные сцены; скролл плавный (НЕ резкий scroll-snap), GSAP ScrollTrigger снапит мягко.
- Заголовки выезжают построчно из-под маски (SplitType, stagger ~80ms).
- Переходы между страницами: тёмная шторка с названием страницы (`template.tsx` + GSAP). 
- Прелоадер при первом входе за сессию: счётчик 0–100 + «Влад Лямин», ≤1.5s, sessionStorage.
- Один WebGL-акцент: **ogl** hover-дисторшн на AI-портрете (главная + /about). Больше WebGL нигде.
- Микро: магнитные кнопки, ховер строк-списков — инверсия лаймом, ховер строк-постеров — курсив + сдвиг, цифры proof-блока отсчитываются при появлении.
- `prefers-reduced-motion`: все анимации отключаются до fade-in, Lenis выключен, прелоадер скипается. Мобайл: без пиннинга тяжёлых сцен, дисторшн выключен.

## 6. Страницы

**Главная — 8 глав** (светлая→тёмная волнами):
1. Hero (светлая): позиционирование с обведённым «системы», портрет с дисторшном, CTA «Пройти AI-аудит» + «Написать в Telegram», рукописная пометка.
2. Цифры (тёмная): три крупные цифры Literata с моно-подписями, отсчёт при появлении.
3. Манифест (тёмная): постер-утверждение + негатив-триада нумерованными строками.
4. Метод (светлая): постер «Аудит. Сборка. Масштаб.» — активное слово заливкой, остальные контуром, переключение при скролле; этапы без упоминания инструментов.
5. Кейсы (тёмная): нумерованные строки с инверсией-ховером, метаданные — результат («60 Ч/МЕС»), не стек.
6. Точки входа (светлая): порядок — Гайд → Консультация → Аудит → Внедрение.
7. Обо мне тизер (тёмная): портрет + «Каждую систему собираю сам.» + рукописная подпись.
8. Финал (светлая): «Готовы строить систему?» с ghost-словом, магнитная CTA-кнопка, футер.

**/about** — тёмная: постер «Строю системы. Своими руками.», портрет с дисторшном, таймлайн пути (лаймовые точки), финальная глава светлеет — принципы «Скучный AI, который работает» + CTA в Telegram.

**/products** — светлая: продукты гигантскими строками-постерами (ховер: курсив + сдвиг + метка у курсора «Открыть»), каждая ведёт на /products/[slug] со шторкой. Детальные страницы — та же постер-типографика, покупка через lava.top как сейчас.

**/audit** — тёмная, механика сохраняется (7 шагов, клиентская форма): один вопрос на экран крупно, ответы большими кнопками, вертикальная шторка между шагами, HUD показывает «Шаг N / 7» и «≈ 4 минуты».

**/blog** — светлая индекс-лента: дата моно + заголовок Literata (ховер — курсив) + мини-обложка. Статья: заголовок-постер, обложка, оглавление сбоку моно. Тело статьи — текущий `app/blog/blog.css` с обновлёнными токенами (шрифты/цвета), структуру не трогаем. ISR/фиды/sitemap без изменений.

**/vibecoding** — привести к новым токенам без полной переработки (вне ядра скоупа).

## 7. Медиа

Живых фото/видео нет. Визуал: типографика, код-анимации и **AI-портреты** (Влад даёт референсы лица, генерим сеты под светлую/тёмную главы; стиль — ч/б, зернистый, без глянца). Скрины систем в кейсах — по возможности, иначе типографические плейсхолдеры.

## 8. Технически

- Стек: Next.js App Router (текущий) + `lenis` + `gsap`/`ScrollTrigger` + `split-type` + `ogl` (одна точка) . Без three.js, без Barba (переходы — `template.tsx`), без framer-motion (GSAP хватает).
- Хостинг: тот же Timeweb VPS; бюджет JS держать разумным (ogl+gsap+lenis ≈ 100KB gz). Сборка на сервере с swap — без изменений.
- Сносится: `components/home/*` (signal-from-noise: SystemSection, SignalSection, engine, particle maps, halftone-генератор из scripts, `public/landing.html`, отладочные png/jpeg из корня репо). Nav/Footer переписываются под HUD.
- Сохраняется без изменений логика: пайплайн блога, cron, Supabase, продуктовые данные `lib/products.ts`, лид-механика аудита.
- Обновляется: `lib/lvmn-features.ts` (фрейм «системы»), глобальные токены в `globals.css`, layout-шрифты.
- SEO: заголовки/меты сохранить или улучшить; контент страниц остаётся серверным HTML (анимации — прогрессивное улучшение), JSON-LD блога не трогаем.

## 9. Вне скоупа

- Реальная фотосессия, видео-контент.
- Переработка тела статей блога и пайплайна генерации.
- Новые продукты/цены, изменение воронки аудита по сути.
- Английская версия.

## 10. Критерии приёмки

- Все страницы в новой системе, HUD работает везде, светлая/тёмная драматургия на каждой странице.
- Ни одного упоминания стека и ни одного слоп-паттерна в видимом тексте.
- Lighthouse mobile ≥ 85 perf, CLS < 0.1; `prefers-reduced-motion` полностью поддержан.
- Воронка кликается: гайд/консультация/аудит/внедрение достижимы с главной в 1 клик, Telegram — из HUD с любого экрана.
