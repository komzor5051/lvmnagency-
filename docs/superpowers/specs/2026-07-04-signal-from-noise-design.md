# Главная vladlyamin.ru — «Сигнал из шума»

Дата: 2026-07-04. Статус: утверждена Владом.

## Цель

Убрать «базовость» главной страницы: превратить её в непрерывный scroll-рассказ
с одной сквозной механикой — портрет Влада, собранный из частиц, распадается
в поток данных, собирает схему AI-системы и в финале возвращается чётким фото.
Метафора позиционирования: «из хаоса инструментов я собираю систему».

Идентичность не меняется: White + Lime DS (`app/globals.css`), Inter Tight /
Onest / Caveat, радиус 0, без теней, без эмодзи, без AI-slop.

Скоуп: только главная (`app/page.tsx` и `components/home/`). Остальные страницы
не трогаем. OpenRouter/генерация медиа не используются — все эффекты
производятся программно из `public/portrait.jpg` (канонический портрет,
уже используется в Hero и AboutTeaser).

## Структура страницы — 5 глав

Каждая глава самодостаточна: при отключённой анимации (reduced-motion, мобила,
слабый девайс) выглядит как качественная статичная секция.

1. **Хиро «Проявление»** — из серого шума точек за ~0.5 с собирается портрет
   в halftone-растре (чёрные точки, лаймовые акценты). Заголовок остаётся
   текущий («Фаундеры тратят часы на задачи, которые AI решает за минуты»),
   слова появляются кинетически с задержкой. Заголовок и CTA рендерятся
   сервером — LCP не зависит от canvas.
2. **«Система»** — при скролле портрет распадается в поток частиц; поток
   перетекает вниз и собирает схему пайплайна: заявка → бот → CRM → отчёт.
   Подписи узлов (DOM) появляются по мере сборки. Заменяет содержимое
   TeachingStrip + DarkBusiness (их тексты переезжают в подписи и абзацы главы).
3. **«Цифры»** — поток частиц «ударяет» в счётчики кейсов (65%, ×4, −3ч/день,
   0 мин), числа докручиваются. Ниже — текущая таблица кейсов без изменений.
4. **«Точки входа»** — продукты из `lib/products.ts` (гайд 990 ₽, консультация
   5 000 ₽, AI-аудит 15 000 ₽, AI Operating System от 150 000 ₽). Карточки
   прорисовываются штрихами/частицами при входе во viewport. Обычный DOM,
   лёгкие анимации, без pinned-скролла.
5. **«Сигнал»** — частицы стягиваются в чёткий фотографический портрет
   (переход от halftone к `portrait.jpg` через маску), рукописная подпись
   Caveat, финальный CTA «Разберём вашу задачу вместе — за час».

Сохраняются: Nav, Footer, CourseBanner (между главами 4 и 5), NotStrip
(«не агентство / не курс / не разовый проект») — между главами 2 и 3.

## Архитектура

- **Один fixed canvas-слой** на всю страницу (z-index под контентом DOM).
  Движок частиц — vanilla TypeScript, 2D canvas, 2–4 тыс. точек. Three.js
  не используется.
- Частица = позиция + целевая «карта». Карты: (a) halftone-маска портрета,
  (b) узлы и рёбра схемы пайплайна, (c) точки финального портрета.
  Скролл (GSAP ScrollTrigger, scrub) интерполирует частицы между картами;
  анимация обратима при скролле вверх.
- **Контент — обычный DOM поверх canvas**: текст остаётся текстом (SEO,
  доступность, копирование).
- Halftone-карта генерируется **на билде**: `scripts/generate-portrait-map.ts`
  читает `public/portrait.jpg`, строит сетку точек с яркостями, пишет JSON
  (~50–100 КБ) в `public/portrait-map.json`. Тот же скрипт экспортирует
  статичные halftone-изображения для fallback. В рантайме фото не
  обрабатывается.
- Код: `components/home/engine/` — `particles.ts` (движок), `maps.ts`
  (загрузка/интерполяция карт), `scroll.ts` (связка со ScrollTrigger),
  `CanvasStage.tsx` (клиентский компонент-обёртка). Главы — рефактор
  существующих компонентов в `components/home/`.
- GSAP уже в зависимостях проекта.

## Деградация и производительность

- Canvas отключается и заменяется статичными halftone-изображениями + CSS-fade
  при любом из условий: `prefers-reduced-motion`, ширина < 768 px,
  FPS < 40 за первые ~0.5 с работы движка.
- Бюджет: код движка ≤ ~15 КБ gzip; `portrait-map.json` грузится лениво после
  LCP; хиро-текст серверный.
- Страница обязана быть полноценной с полностью отключённым движком.

## Тестирование

- `npm run build` + `npm run lint`.
- Playwright: скриншоты каждой главы на 3 брейкпоинтах (360 / 768 / 1440)
  + отдельный прогон с эмуляцией reduced-motion (статичный вариант).
- Ручная проверка: скролл вниз и вверх (scrub обратим), FPS в DevTools
  Performance, отсутствие layout shift от canvas.

## Деплой

Как обычно для проекта: rsync на Timeweb VPS + `npm run build` на сервере +
`pm2 restart lvmn` (см. CLAUDE.md проекта). Vercel не используется.
