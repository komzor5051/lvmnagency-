# Content pivot: блог переходит на Claude / Claude Code

## Контекст

Блог сейчас генерирует статьи про AI-автоматизацию бизнеса в целом (n8n, Telegram-боты,
ChatGPT для бизнеса). Пивот: полностью заменить тематику на Claude и Claude Code —
фишки, юзкейсы, как пользоваться, конкретные приёмы, которые читатель может сразу
применить. Контент-завод должен ресерчить интернет, официальные материалы Anthropic,
X и блогеров про Claude, и на основе этого готовить статьи.

Это полная замена тематики, не параллельный поток. Аудитория расширяется: не только
фаундеры/предприниматели, но и разработчики, использующие Claude Code.

## Пиллы контента

`topic-miner` ротирует темы по 4 направлениям (~2-3 темы на каждое из 10 генерируемых):

1. **Claude.ai для нетехнических** — Projects, Artifacts, стили ответов, голосовой
   ввод, работа с документами
2. **Claude Code для разработчиков** — skills, hooks, MCP, субагенты, workflow,
   конкретные конфиги
3. **AI-автоматизация бизнеса через Claude** — API, агенты, интеграция с ботами/n8n
   (мост к текущей экспертизе Влада)
4. **Сравнения и новости** — Claude vs ChatGPT/Gemini, разборы обновлений и релизов
   Anthropic

## Изменения по файлам

### `lib/pipeline/topic-miner.ts`

- Промпт переписывается под 4 пилла выше, с требованием распределять темы поровну.
- Ресерч через `searchSources()` (Exa) — новые запросы: "Claude Code фичи обновления",
  "Claude.ai use cases", "Anthropic release notes", "Claude tips workflow".
- Новый источник: прямой `fetch()` HTML-страниц `docs.claude.com` (changelog/release
  notes) и `anthropic.com/news`, текст скармливается в `trendSummary` тем же образом,
  что и результаты Exa (без новых npm-зависимостей — регуляркой или напрямую сырым
  HTML в промпт Gemini, модель сама вытащит суть).
- Убрать полностью: импорт и вызовы `collectSeedQueries`/`getSearchVolume` из
  `lib/wordstat.ts`, `WORDSTAT_SEEDS`, блок буста score по объёму спроса.
  Score считается только моделью (1-10).
- Поле `search_volume` в insert остаётся `0` (схему Supabase не трогаем).
- Примеры хороших заголовков обновляются под новую тематику (например: "Claude Code
  сам чинит баги — вот как я это настроил", "MCP-сервер за 20 минут: подключил Claude
  к своей базе данных").
- Запрещённые темы: убрать пункт про "мультичаты/агрегаторы — не профиль Влада"
  (нерелевантно), добавить "не выдумывать несуществующие фичи Claude/Anthropic".

### `lib/wordstat.ts`

Удалить файл целиком — единственный потребитель (topic-miner) после правки в нём
не нуждается.

### `lib/pipeline/style-guide.ts`

- Аудитория: фаундеры/предприниматели **и** разработчики, использующие Claude Code.
- Терминология "ИИ вместо AI" остаётся, но с явным списком исключений — технические
  термины не переводятся: `MCP`, `hook`, `skill`, `subagent`, `slash command`,
  `agent`, `prompt`, `CLI`.
- Снять ограничение "никаких API/деплой без объяснения на пальцах" для статей из
  пилла "Claude Code для разработчиков" — там это ожидаемая лексика.
- Остальные правила (запрещённые фразы, вариативность длины предложений/абзацев,
  разговорные приёмы, картинки) — без изменений по существу, только предметная
  область в примерах меняется с "автоматизация бизнеса" на "Claude/Claude Code".

### `lib/pipeline/writer.ts`

- Структура статьи:
  1. Хук + краткий пересказ — без изменений.
  2. Основная часть — пошагово, с конкретными командами/промптами/конфигами.
  3. Секция "как это работает на практике" — гибкая: кейс с цифрами (бизнес-пиллы)
     ИЛИ конкретный воркфлоу/приём с результатом (технические пиллы). Заменяет
     жёстко заданную секцию "кейс из реальных проектов Влада".
  4. FAQ — без изменений (вопросы в виде поисковых формулировок).
  5. **CTA (новый, единый для всех статей):** ведёт на гайд «AI вместо команды»
     (`https://vladlyamin.ru/products/guide`, 990 ₽) вместо CTA на консультацию в
     Telegram. Формулировка CTA-абзаца адаптируется под тему статьи (для Claude Code —
     акцент на "готовые команды и системы", для Claude.ai — на "профиль под задачи и
     экспертные режимы"), но сам продукт, цена и содержание гайда берутся из
     `lib/products.ts` как есть, не выдумываются заново и не переупаковываются.
- Картинки: правило "обложка + 1-2 внутри" остаётся, тематика метафор смещается на
  "человек работает с Claude/терминалом/кодом", без буквальных скриншотов UI.
- Убрать жёсткое "аудитория — фаундеры, не технари" из финальных требований к тексту.

### `lib/pipeline/editors.ts`

- Редактор `factcheck`: заменить проверки 5-6 (список реальных/запрещённых услуг
  Влада) на проверку точности утверждений про Claude/Anthropic — не выдуманы ли
  модели/фичи/цены, не устарели ли даты релизов, соответствуют ли утверждения
  источникам (`sourcesContext`).
- Юридические проверки (VPN, политика, гарантии дохода) — без изменений.
- Редакторы `structure`/`coherence`/`anti-slop` — без изменений по существу.

### `lib/pipeline/cover-style.ts`

Точечная правка текста в `buildCoverPrompt` и `buildInlinePrompt`: «статья в блоге об
AI и автоматизации бизнеса» → «статья про Claude и AI-инструменты». Кинематографичная
a16z-эстетика, композиция, свет, цветокоррекция — без изменений.

### `CLAUDE.md` (lvmn-site)

- Обновить раздел Architecture — описание пайплайна отражает новую тематику.
- Убрать `WORDSTAT_TOKEN` из таблицы Environment Variables.
- Убрать `lib/wordstat.ts` из Key Files.

## Не в скоупе

- `lib/lvmn-features.ts` (оффер Влада) — не меняется.
- `lib/pipeline/publisher.ts`, `image-generator.ts`, `telegram.ts` — не меняются.
- Продукт-гайд `/products/guide` (`lib/products.ts`) — не меняется и не

## Риски / открытые вопросы

- Прямой fetch `docs.claude.com`/`anthropic.com/news` может отдавать JS-рендер без
  серверного HTML — если парсинг не даст полезного текста, этот источник можно
  тихо пропускать (best-effort, как сейчас сделано с Wordstat), не блокируя
  генерацию тем.

## Постфактум (2026-07-09)

- **Cron сломан на проде.** `api.exa.ai` блокирует IP VPS на уровне Cloudflare
  (403, подтверждено curl с полными браузерными заголовками) — это гео/IP-блок,
  не проблема ключа. Тот же класс блокировки, из-за которой раньше отказались от
  Vercel для хостинга. `mine-topics` и `generate` на сервере сейчас не работают.
  Временное решение: статьи генерируются вручную — `npx tsx scripts/run-pipeline.ts`
  запускается с не-RU машины (тот же Supabase), публикация мгновенная, без деплоя.
  Постоянное решение (не сделано): прокси для исходящих Exa-запросов с VPS —
  обсуждали, отложили до отдельной задачи.
- Добавлен `lib/claude-setup-context.ts` — реальный (client-free) Claude Code
  setup Влада (skills, MCP, паттерны субагентов/workflow). `writer.ts` теперь
  опирается на него для статей пилла "Claude Code для разработчиков" вместо
  общих советов из веб-ресерча.
- В `lvmn_blog_topics` накопилось ~350 pre-pivot тем (n8n/ROI/ChatGPT-generic);
  archived (`status: "skipped"`), кроме 10 реальных Claude-тем из первого прогона
  нового `topic-miner`. Ручной прогон `run-pipeline.ts` выбирает тему по
  наибольшему score среди `status: "pending"` — если появится офф-топик пост,
  сначала проверить статус выбранной темы, а не считать это багом кода.
