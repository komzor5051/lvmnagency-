# Главная «Разворот» + VSL в продуктах — дизайн

Дата: 2026-09-02. Статус: утверждено Владом (вариант А из трёх, лайм вместо синего,
продукт «AI в работе команды» снимается).

## Зачем

Влад больше не внедряет AI в команды. Он обучает, консультирует и помогает одному
человеку собрать личную систему работы на Claude. Текущая главная (bento-плитки,
блоки «Как проходит работа», «Что меняется после внедрения», «Что останется у вас
после») продаёт внедрение и выглядит скомканно. Нужна главная с воздухом, которая
показывает продукты и позиционирование, плюс возможность встроить VSL-видео в
любой продукт.

## Структура главной

Шапка: логотип-имя, ссылки **Продукты · Обо мне · Блог · Аудит**, кнопка «Начать с гайда».

1. **Hero** — заголовок «Помогаю собрать личную систему работы на Claude» (слово
   «личную» с лайм-маркером за текстом), лид, две кнопки (Смотреть продукты / Кто я),
   справа колонка из трёх фактов: 50+ обучил, 40+ систем, с 2022.
2. **Продукты** — оглавление (index): строка = тип · заголовок · описание · цена.
   Порядок: гайд Claude 990 ₽, ContentOS 2 490 ₽, консультация 3 850 ₽, AI-аудит 15 000 ₽,
   мини-курс «скоро». Ссылка «Все форматы подробно» на /products.
3. **Обо мне** — портрет ч/б слева, справа заголовок, одна курсивная тезис-фраза
   («Не внедряю AI в команды…»), абзац, ссылка на /about.
4. **Блог** — три последних статьи из `getPublishedPosts()`, дата · тег, заголовок, линия.
5. **Финальный CTA** — «Начни с гайда за 990 ₽», кнопка.
6. FAQ на главной убирается (вопросы про внедрение). Sticky-CTA гайда оставить.

Удаляются секции: кейс «Что меняется после внедрения», «Как проходит работа»,
«Принципы / Что останется у вас после».

## Визуальный язык

- Фон белый, чернила `#15161a`, приглушённый `#6b6e78`, линии `#e6e7ea`.
  Акцент — лайм `#C8F04C` (`--lime`) **только как заливка**: маркер за словом,
  кнопки на ховере, полосы. Никакого лайма как цвета текста.
- Шрифты через next/font/google, subset cyrillic: **Cormorant Garamond** (display,
  400/500, italic) для h1–h3 и цен, **Golos Text** (body), **JetBrains Mono** для
  эйрбоу-подписей. Inter Tight/Onest остаются для остальных страниц до их переработки.
- Радиус 0, теней нет. Сетка 1240px, отступы секций 120px на десктопе, 80px на мобиле.
- Вертикальный ритм: hero 140px сверху, каждая секция отделена hairline-линией.

## Анимации (по полигону, рекомендация)

Полигон: артефакт «Полигон анимаций». Рекомендованный набор, если Влад не выберет
другое:

- Строки продуктов — **1b**: лайм-маркер проезжает под заголовком (0.55s, cubic-bezier(.7,0,.2,1)).
- Кнопки — **2b**: лайм поднимается снизу, текст темнеет.
- Ссылки шапки — **3a**: подчёркивание рисуется слева направо.
- Карточки блога — **4a**: линия под карточкой становится чёрной.
- Появление hero — **5b**: слова поднимаются из-под линии; остальные секции — **5a** мягко снизу.
- Всё через CSS-переходы и IntersectionObserver (компонент `components/motion/Reveal.tsx`
  уже есть — переиспользовать). `prefers-reduced-motion` отключает всё.

## VSL-видео в продуктах

Любой продукт может показать видео-продажник над описанием.

- `lib/products.ts`: новое поле `vsl?: { embedUrl: string; poster: string; title: string; ratio?: "16/9" | "9/16" }`.
  Хостинг-агностично: Kinescope, VK Video, YouTube, любой iframe-URL.
- Компонент `components/products/Vsl.tsx` — фасад: постер + кнопка «Смотреть»,
  iframe грузится только по клику (нет тяжёлого iframe в first paint). Клик шлёт
  событие `vsl_play {product}` через PostHog. Постер — `next/image` из `/public`.
- Расположение на `/products/[slug]`: сразу под заголовком и ценой, до описания и
  обложки; если есть `vsl`, обложка-баннер не показывается.
- Схема: в JSON-LD продукта добавляется `video: VideoObject {name, thumbnailUrl, embedUrl}`.
- Первым подключается гайд Claude; URL и постер даёт Влад.

## Технически

- Главная: новый `app/page.tsx` + `app/home.css` (scoped-стили, класс `.rz-*`), старые
  `bento-*` компоненты не удаляются, пока их используют /products и /about.
- Шапка: `components/studio/StudioNav.tsx` — новые ссылки и стиль под «Разворот»,
  применяется на всех страницах.
- Метаданные и JSON-LD главной сохранить. Sitemap не трогать.
- Проверка: `npm run lint`, `npm run build`, визуально в браузере на 1440 и 375,
  Lighthouse LCP не хуже текущего (h1 текстовый, портрет lazy).
- Деплой по обычной схеме (snapshot + rsync + build + pm2).
