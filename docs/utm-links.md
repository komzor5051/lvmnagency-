# UTM-метки на собственных ссылках

## Зачем

За последние 14 дней 76% визитов на сайт числятся прямыми заходами. Часть из
них — реальные переходы из Телеги: Telegram Desktop и приложение Instagram не
передают реферер, поэтому сервер видит их как «человек пришёл ниоткуда».

Пока эти переходы неотличимы от прямых, цифру «сколько дал сайт из поиска»
нельзя посчитать вычитанием. UTM-метка решает это на своей стороне:
`utm_source` имеет приоритет над реферером в классификаторе
`lib/traffic-source.ts`, и размеченный переход попадает в свой канал даже без
реферера.

## Схема

```
https://vladlyamin.ru/products?utm_source=telegram&utm_medium=social&utm_campaign=guide-launch
```

| Параметр | Что писать | Зачем |
|---|---|---|
| `utm_source` | `telegram`, `instagram`, `threads`, `linkedin`, `youtube` | Площадка. Определяет канал. |
| `utm_medium` | `social` для постов, `bio` для ссылки в шапке профиля, `story` для сторис | Разделяет разовый пост и постоянную ссылку. |
| `utm_campaign` | Что именно продвигается: `guide-launch`, `case-edsy`, `audit` | Позволяет сравнить запуски между собой. |

Источники из таблицы `UTM_SOURCE_CHANNEL` в `lib/traffic-source.ts` раскладываются
по каналам автоматически. Новую площадку надо сначала добавить туда, иначе она
попадёт в «Другие сайты».

## Правило

Размечается каждая ссылка на сайт, которую ты ставишь руками: посты, шапка
профиля, закреп в канале, описание под видео.

Не размечается ничего из того, что публикуется на самом сайте: внутренние
ссылки, sitemap, RSS. Метка на внутренней ссылке обнулит исходный канал
визита и припишет переход соцсетям.

## Проверка

После разметки соцсети должны перестать расти за счёт «прямых»:

```bash
npx tsx scripts/traffic-report.ts --days 14
```
