# Регистрация в Claude из России: рабочий маршрут и почему банят

Россия не входит в список поддерживаемых регионов Anthropic. Сайт и API не открываются с российского IP, карты Visa, MasterCard и МИР не проходят на чекауте. При этом Claude Code у меня работает каждый день, и это не единичное исключение.

В мае 2026 прошла волна массовых блокировок российских аккаунтов без предупреждения. Цифра «1,45 млн банов», которая гуляет по статьям, первоисточником Anthropic не подтверждена — это оценка, но порядок величины показательный. Ниже механика блокировки и маршрут регистрации. Полный список сервисов с ценами лежит в гайде.

## Почему банят: сигналы из разных стран

Антифрод Anthropic смотрит не на один признак, а на совпадение сразу четырёх: IP, карта, номер телефона, адрес выставления счёта. IP из одной страны, а карта из другой — статистически это фрод. Даже если человек ни в чём не виноват.

Второй по частоте триггер — диапазоны публичных VPN. Банковский антифрод (Stripe) знает их наизусть и режет и оплату, и аккаунт следом за ней. Отсюда правило, из которого следует всё остальное: IP, номер, карта и адрес биллинга должны быть из одной страны. Не «примерно похожей», а одной.

С 8 июля 2026 добавился ещё один риск. Anthropic обновил политику конфиденциальности: сервис может запросить подтверждение личности — документ, дату рождения, селфи-проверку через сервис Persona. Для аккаунтов, оформленных не на себя, это отдельная угроза, которую никакой прокси не закрывает.

Вывод из майской волны банов простой: подход «сделаю как попало, а если забанят — обжалую» больше не работает. Аккуратность с самого начала даёт кратно больше, чем разбор последствий постфактум.

## Маршрут регистрации по шагам

**Почта.** Не .ru-домен. Gmail, Outlook или Proton — mail.ru и yandex часто не проходят на этапе подтверждения.

**Доступ.** Не публичный VPN — их диапазоны антифрод знает наизусть. Дольше живут аккаунты на резидентском прокси или мобильном интернете через иностранную eSIM. IP один и тот же постоянно, включён на каждый запрос, а не только на логин. Из приемлемых юрисдикций — США, ЕС, Казахстан, Грузия, Армения, Турция.

**Телефон.** Виртуальный номер той же страны, что и IP. Через SMS-активацию номер обычно арендуется на короткое время — код вводится сразу после получения.

**Оплата.** Карта той же страны, что IP и номер, с billing-адресом там же. Есть два пути, и они по-разному надёжны.

Надёжнее — карта обычного зарубежного банка: Казахстан, Армения, Грузия. Такие банковские BIN антифрод пропускает спокойнее, чем виртуальные карты, потому что за ними стоит настоящий банк, а не финтех-прослойка.

Быстрее, но менее предсказуемо — российские сервисы выпуска виртуальных карт с пополнением через СБП, например Плати по Миру. Цена выпуска на июль 2026 — от 2 990 рублей, пополнение без комиссии. Компромиссный вариант — prepaid-финтех-карты. Они чаще ловят отказ платежа на чекауте и повышают риск бана самого аккаунта, не только транзакции.

Рынок таких сервисов перетряхивается каждые несколько месяцев. Условия и отзывы стоит проверять непосредственно перед оплатой, а не по чужой инструкции полугодовой давности — то, что работало весной, может не работать летом.

Есть и третий путь — маркетплейсы цифровых товаров, где подписку оформляют «под ключ», без своей карты и номера вообще. Плата за удобство — ты доверяешь посреднику весь аккаунт, включая рабочую переписку внутри него.

**Прогрев.** Новый аккаунт 3-7 дней работает в лёгком режиме, прежде чем на него грузится серьёзная задача. Резкий скачок активности на свежем аккаунте сам по себе сигнал для антифрода.

Собрал это в чек-лист:

```
- IP, карта, номер телефона, billing-адрес — одна страна
- резидентский прокси или eSIM вместо публичного VPN, включён всегда
- почта без .ru-домена
- 3-7 дней лёгкого режима перед нагрузкой
- никаких сторонних клиентов и обёрток поверх официальной подписки
- рабочие файлы живут локально, не только в истории чатов
```

## Правовая сторона — коротко

Для частного лица в России использование VPN и доступ к Claude не нарушает закон. Запреты касаются операторов и распространения средств обхода, а не пользователя. Риск лежит в другой плоскости — в условиях использования самого Anthropic. Последствие нарушения — блокировка аккаунта и потеря оплаченного, а не юридическая ответственность.

Для компаний с российским контролем больше 50% доступ запрещён политикой Anthropic напрямую, с 2025 года это прописано в условиях использования. Легальный путь для такого бизнеса — работающие в России API-агрегаторы или зарубежное юрлицо. Условия Anthropic меняются, поэтому актуальную Usage Policy стоит перечитать перед коммерческим использованием — это ориентир, а не юридическая консультация.

## Если всё же забанили

Апелляции по опыту сообщества срабатывают редко — на уровне единиц процентов. Отправить стоит: спокойным тоном, на английском, с фактами. Но параллельно сразу переключаться на план Б, а не ждать ответа неделями.

## План Б: Claude Code без подписки

Самый спокойный вариант — вообще не заводить подписочный аккаунт, а запускать Claude Code на API-ключе. Подписки нет — банить нечего, платишь за фактический расход токенов.

Claude Code умеет работать через агрегатор OpenRouter по нативному протоколу Anthropic — три переменные окружения:

```
export ANTHROPIC_BASE_URL="https://openrouter.ai/api"
export ANTHROPIC_AUTH_TOKEN="ключ-openrouter"
export ANTHROPIC_API_KEY=""
```

Anthropic эту схему не одобряет и не поддерживает официально — документирует её сам OpenRouter. Рассчитывать приходится на себя. Пополнение OpenRouter тоже требует зарубежной карты или крипты, то есть той же логики из шага «оплата» выше.

Есть и российские агрегаторы вроде ProxyAPI — оплата в рублях, без VPN и иностранного номера. Перед оплатой стоит убедиться, что агрегатор отдаёт Anthropic-совместимый endpoint — тогда Claude Code подключается теми же тремя переменными.

Честная арифметика: при плотной ежедневной работе API выходит дороже подписки Max. Но именно поэтому это план Б, а не основной путь — план Б держат наготове, а не выбирают по умолчанию.

Хорошо совмещается с этим третий вариант — запускать Claude Code не на своём ноутбуке, а на дешёвом зарубежном VPS по SSH. Стабильный иностранный IP из коробки, никакого рассинхрона геолокации между сессиями.

Именно из-за риска бана рабочие файлы, CLAUDE.md и скиллы должны жить у тебя локально, а не только в истории чатов Claude. Тогда бан не останавливает работу. Переносишь наработки на новый доступ и продолжаешь в тот же день.
