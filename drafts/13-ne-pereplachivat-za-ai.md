# Как перестать платить за AI, которым почти не пользуешься

Разбираем, что доступно из России, сколько реально стоит API против подписки, и когда пора отменять то, что оплачивается по инерции.

Курс доллара к рублю на 25 сентября 2026 года — 84,9057 ₽ по данным ЦБ. Подписка Claude Pro за 20 долларов — это 1698 ₽ по официальному курсу. Проверил публичные страницы нескольких сервисов-посредников на дату публикации — фиксированный процент наценки никто из них не публикует. Цена идёт по «внутреннему коммерческому курсу», близкому к курсу наличной валюты в банках РФ, и уточняется у оператора в Telegram под конкретную сумму. По факту это то же самое отклонение от курса ЦБ, просто без заявленного числа — сравнивайте итоговую сумму в рублях с курсом ЦБ на день оплаты, а не с готовым процентом. Разница с оплатой через API всё равно исчисляется ценой нескольких тысяч сообщений.

## 1. Что реально доступно из России

Прямая оплата Claude.ai и ChatGPT Plus российской картой не проходит. Anthropic и OpenAI обрабатывают платежи через Stripe. Карты российских банков блокируются на уровне BIN-кода — сразу, без попытки списания.

Рабочих обходов три. Виртуальная карта в Wise или Revolut с привязкой к стране, где сервис работает. Оплата через посредника за рубли с комиссией сверху. Оплата криптовалютой напрямую или через сервисы вроде Taria Gift. Каждый вариант добавляет к цене подписки либо комиссию, либо время на настройку.

## 2. Бесплатные тарифы — не иллюзия, а рабочий инструмент для лёгких задач

У Claude и ChatGPT есть бесплатный доступ без карты и без VPN для оплаты — регистрация через email. Ограничение по лимитам жёстче, чем на Pro, и пятичасовое окно у Claude действует и на бесплатном тарифе.

Для разовых задач — свести таблицу, переформулировать письмо, разобраться в тексте закона — бесплатного тарифа обычно хватает. Платить стоит начинать, когда упираешься в лимит регулярно, а не один раз в месяц.

## 3. Оплата API через посредников: OpenRouter и аналоги

OpenRouter даёт доступ к моделям Anthropic, OpenAI и десяткам других через единый API и один счёт. Платите не за подписку, а за токены — сколько использовал, столько и списалось.

Комиссия за пополнение баланса официальная. 5,5% с минимумом 0,80 доллара за оплату картой через Stripe. 5% за пополнение криптовалютой. Российские карты Сбера, Т-Банка и Альфы OpenRouter тоже отклоняет по BIN-коду. Доступ остаётся через крипто-маршрут или карту с иностранным BIN.

Сама модель через OpenRouter стоит столько же, сколько у первоисточника, плюс комиссия площадки на вход. Наценки на токены сверху нет — это подтверждает документация сервиса.

## 4. Сколько это стоит на самом деле: API против подписки

Актуальная цена Claude Sonnet напрямую у Anthropic — 2 доллара за миллион входных токенов и 10 долларов за миллион выходных. Дальше — расчёт, а не факт: беру среднее сообщение с историей диалога как 2000 входных и 500 выходных токенов. Это оценка для сравнения, не измерение вашей личной переписки. У вас конкретные числа могут отличаться в разы.

При этой оценке 100 сообщений в месяц обходятся примерно в 0,9 доллара — 76 ₽. 500 сообщений — 4,5 доллара, 382 ₽. 1000 сообщений — 9 долларов, 764 ₽. Подписка Pro при этом стоит 20 долларов, 1698 ₽ по курсу ЦБ. Через посредника выйдет дороже официального курса — на сколько именно, зависит от курса оператора в день оплаты, фиксированного процента никто из них не публикует.

Вывод из расчёта простой. Меньше тысячи коротких сообщений в месяц, без гигантских файлов и часовых агентных сессий — подписка почти наверняка переплата. Окупается она там, где сообщений в разы больше или каждое тянет десятки тысяч токенов контекста. Например, в Claude Code на весь рабочий день.

## 5. Клиенты для API без подписки: Jan и Chatbox

Jan — бесплатное десктопное приложение с открытым кодом. Работает как с локальными моделями на вашем железе, так и с облачными провайдерами через свой ключ, включая Anthropic и OpenAI. Данные локальной модели не покидают компьютер, но локальные модели заметно уступают Sonnet и Opus по качеству на сложных задачах.

Chatbox — кроссплатформенный клиент для Windows, macOS, Linux, iOS, Android и веба. Подключается к OpenAI, Anthropic, Gemini и агрегаторам вроде OpenRouter по собственному ключу пользователя (BYOK). Сам клиент бесплатен, платите только за токены у провайдера.

Оба варианта решают одну и ту же задачу — платить по факту использования, а не за место в подписке, которое пустует три недели из четырёх.

## 6. Что теряете при переходе на API

У подписки есть то, чего нет в голом API. Веб-интерфейс, синхронизация между устройствами, память между чатами на Pro, встроенные инструменты вроде генерации артефактов и запуска кода без своей обвязки. API даёт только доступ к модели. Интерфейс, память и хранение истории собираете сами или через клиент вроде Chatbox.

Для разработчика или человека, который готов настроить клиент один раз, это не проблема. Для человека, который просто хочет открыть браузер и написать сообщение, экономия в деньгах обернётся потерей времени на настройку. И тут разумнее остаться на подписке, даже переплачивая по чистой математике токенов.

## 7. Как правильно отменять подписку

Отмена зависит от того, где вы подписались, а не от того, где привыкли заходить. Проверьте выписку банка или карты — там видно, кто именно списывает деньги.

Подписались через сайт claude.ai — заходите в Settings → Billing, листаете до конца страницы и жмёте Cancel Plan. Подписались через приложение на iPhone — отмена только через Apple: Настройки → имя профиля → Подписки. Через Android — через Google Play или через раздел Billing в самом приложении Claude.

Важная деталь: отмена останавливает будущие списания, но не возвращает деньги за текущий период. Доступ на уровне Pro или Max сохраняется до конца оплаченного цикла, потом аккаунт тихо падает на бесплатный тариф.

## Где это ломается

- **Забытая пробная подписка.** Триал заканчивается, карта списывает полную цену в валюте по курсу банка, который выше курса ЦБ на несколько процентов.
- **Непрозрачный курс посредника.** Фиксированный процент наценки нигде не публикуется — сумму называет оператор в переписке, по своему коммерческому курсу. Сверяйте итог с курсом ЦБ на день оплаты, а не с обещанным где-то диапазоном.
- **Курс на момент зачисления, а не на момент оплаты.** Крипто-платёж на OpenRouter конвертируется по курсу в момент зачисления баланса, а не в момент отправки. При волатильности разница заметна.
- **Локальная модель вместо облачной там, где нужно качество.** Jan экономит деньги, но модель уровня Sonnet или Opus локально не запустить на обычном ноутбуке. Итог хуже, а время на промпты то же.
- **Смешение личных и рабочих трат.** Если подписку в итоге оплачивает клиент или работодатель, перевод на API с почасовым списанием токенов усложняет отчётность, а не упрощает.
- **Забытый способ оплаты.** Часть клиентов вроде Chatbox не работает без собственного API-ключа. Установили приложение, обрадовались, что бесплатное, и упёрлись в пустой экран без ключа.

## Частые вопросы

**Бесплатный тариф вообще годится для работы?**
Для разовых задач — да. Для ежедневной работы с файлами и длинными диалогами упрётесь в пятичасовой лимит быстрее, чем на Pro.

**Что выгоднее при нерегулярном использовании — подписка или API?**
При объёме до тысячи сообщений в месяц без тяжёлых файлов API дешевле в разы. Точку перегиба считайте по своему паттерну, а не по чужому расчёту.

**Платить через посредника — это безопасно?**
Технически да, но это переплата за скорость и удобство. Крипто-маршрут официально поддержан площадками вроде OpenRouter и дешевле по комиссии, но требует освоить покупку и перевод криптовалюты.

**Как выбрать между Jan и Chatbox?**
Jan — если хотите запускать модели локально и минимизировать зависимость от облака. Chatbox — если нужен единый интерфейс под несколько облачных провайдеров с одним ключом на каждый.

Сегодня зайдите в биллинг всех AI-подписок, на которые у вас есть доступ, и посчитайте, сколько сообщений вы реально отправили за последний месяц. Меньше пятисот — переходите на API через посредника. Больше полутора тысяч в день, с файлами и агентными сессиями — подписка остаётся дешевле любого расчёта на бумаге.
