# Какие 20% функций Claude дают тебе 80% результата

Обзор восьми функций Claude, из которых реально работают шесть. Остальные — для команд, а не для соло.

В Claude сейчас больше десятка функций. Проекты, артефакты, память, скиллы, коннекторы, режим research, кастомные стили, выбор модели, Claude Code. Если ты эксперт-соло, большая часть списка тебе не нужна вообще. Разберём, что тянет результат, а что можно выключить и забыть.

## 1. Проекты с инструкциями и базой знаний

Проект в Claude — это папка с постоянным контекстом: инструкции, файлы, история чатов внутри одной темы. Support-центр Claude пишет прямо: «Context is not shared across chats within a project unless the information is added into the project knowledge base» [(support.claude.com)](https://support.claude.com/en/articles/9519177-how-can-i-create-and-manage-projects). То есть без загрузки файлов в базу знаний проекта каждый чат снова стартует с нуля.

Практика для соло: заведи отдельный проект на каждого клиента и отдельный на контент. В инструкции проекта — кто клиент, какой у него стек, какие ограничения. В базу знаний — договор, бриф, последний отчёт. Новый чат внутри проекта подхватывает это без пересказа.

Бесплатный аккаунт ограничен пятью проектами. На платных планах при переполнении базы знаний «Claude will automatically enable RAG mode to expand your project's capacity» [(support.claude.com)](https://support.claude.com/en/articles/9519177-how-can-i-create-and-manage-projects). Claude сам переходит на поиск по фрагментам вместо загрузки файла целиком.

## 2. Кастомные стили под свой голос

Стили меняют не что отвечает Claude, а как: длину, формальность, структуру. Support-центр формулирует это так: «Styles focus exclusively on the shape and feel of the output itself» [(support.claude.com)](https://support.claude.com/en/articles/10685301-using-styles-in-claude-ai). Без сохранённого стиля тебе приходится объяснять тон заново в каждом чате.

Собрать стиль можно двумя путями. Первый — готовый пресет: Normal, Learning, Concise, Explanatory, Formal. Второй — свой стиль из примеров текста, он надёжнее. Claude обобщает и упрощает твои образцы, поэтому черновик стоит переписать вручную и вернуть реальные формулировки, а не саммари от модели.

Для эксперта-соло это прямая экономия. Один раз собрал стиль под клиентские отчёты, второй раз под личный блог — и Claude больше не звучит как нейросеть по умолчанию.

## 3. Артефакты для рабочих файлов

Артефакт — это отдельное окно с готовым результатом: HTML-страница, таблица, код, документ. Отличие от обычного ответа в чате — артефакт можно открыть, отредактировать, опубликовать отдельной ссылкой, не листая переписку заново.

Для соло-предпринимателя это способ сдавать клиенту не текст с инструкцией «скопируй в файл». Вместо этого — готовая ссылка: посадочная страница, калькулятор, дашборд. Открыл артефакт — увидел результат сразу, без сборки на своей стороне.

## 4. Память между чатами

Claude запоминает не саммари переписок, а отдельные темы по ходу разговора. Функцию описывают так: «Claude saves memory as a set of individual topics as you chat, rather than summarizing conversations after they end» [(support.claude.com)](https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context). Ты можешь явно попросить «запомни это» — и пункт сохранится отдельной записью, которую видно и можно удалить.

Важная деталь для тех, кто ведёт несколько проектов параллельно: «Each project has its own separate memory space and dedicated project summary» [(support.claude.com)](https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context). Память клиента А не протекает в чат с клиентом Б. Чувствительные темы вроде здоровья или убеждений Claude по умолчанию не сохраняет — это включается вручную в настройках памяти.

Включи память один раз в Settings и больше не думай о ней — она работает фоном, без дополнительных действий с твоей стороны.

## 5. Скиллы под повторяющиеся задачи

Скилл — это набор инструкций и, при необходимости, скриптов. Claude применяет его сам, когда видит подходящую задачу. Для этого нужно включить выполнение кода: «This feature requires code execution to be enabled» [(support.claude.com)](https://support.claude.com/en/articles/12512180-use-skills-in-claude). Часть скиллов встроена — Excel, Word, PowerPoint, PDF. Их Claude подключает без команды от тебя.

Создать свой скилл можно без программирования: «Anyone can create skills by writing instructions in Markdown» [(support.claude.com)](https://support.claude.com/en/articles/12512198-how-to-create-custom-skills). Это способ зафиксировать процесс один раз — например, формат еженедельного отчёта клиенту. Дальше не нужно объяснять его заново в каждом чате.

## 6. Коннекторы к почте и диску

Google Workspace подключается тумблером в окне чата: «click the plus sign in the chat input area, toggle on Gmail, Google Calendar, or Google Drive» [(support.claude.com)](https://support.claude.com/en/articles/10166901-use-google-workspace-connectors). Доступно на всех тарифах, включая бесплатный, с ограничениями по лимитам плана.

Разница в правах критична для рабочего процесса. Gmail работает только на чтение и черновик: Claude готовит письмо, отправляешь ты сам. Google Drive работает и на чтение, и на запись — Claude сохраняет туда сгенерированный файл напрямую. Это снимает рутину поиска писем вручную, но финальное решение — отправить или нет — остаётся за тобой.

## Что можно игнорировать

Режим research — это агентный многошаговый поиск с отчётом за 5–30 минут вместо секунд обычного веб-поиска. Для разовой проверки факта это избыточно. Обычный веб-поиск отвечает быстрее и почти всегда достаточно точно. Держи research в уме для редких случаев — сравнение рынков, разбор конкурентов — и не включай по умолчанию.

Выбор модели вручную для соло-практика почти не нужен. Sonnet — модель по умолчанию, разумный выбор для большинства рабочих задач. Opus имеет смысл только для сложных многошаговых решений. Haiku — там, где важна скорость на простых операциях. Если ты не гоняешь сотни запросов в день и не пишешь сложный код, ручное переключение моделей не изменит результат настолько, чтобы тратить на это внимание.

## Где это ломается

Инструкции проекта путают с базой знаний — файл загружен, а в инструкциях об этом ни слова, и Claude не понимает, что с файлом делать.

Стиль собран из автоматического саммари, а не из реальных твоих текстов — на выходе получается усреднённый деловой тон, который звучит ровно как любой другой чат-бот.

Клиентские проекты не разделены — переписка и файлы одного клиента всплывают в разговоре с другим, потому что всё велось в общем чате без проекта.

Коннектор Google Drive включён, но не проверено, что сохраняется — просишь Claude «сохрани файл», а он молча кладёт его не в ту папку.

Скилл создан один раз и забыт — процесс в бизнесе поменялся, а инструкция в скилле осталась старой, и Claude по ней действует автоматически, без сигнала, что она устарела.

Память выключена по умолчанию для чувствительных тем — рассчитываешь, что Claude помнит контекст со здоровьем или личными обстоятельствами клиента, а он о них не знает, потому что тема не сохранена.

## Частые вопросы

**Нужны ли мне все функции сразу?**
Нет. Для соло-практика хватает пяти-шести: проект с инструкциями, свой стиль, артефакты для сдачи результата, память, один-два коннектора под твою почту и диск.

**Сколько времени уходит на настройку?**
Проект с инструкциями и стиль под голос собираются за час каждый. Коннекторы — несколько минут на подключение. Скилл под конкретный процесс — от часа, в зависимости от сложности.

**Стоит ли переключать модели вручную?**
Для большинства задач эксперта-соло — нет. Sonnet работает по умолчанию и справляется с основным объёмом. Опус подключай только под явно сложную многошаговую задачу.

**Что делать с research-режимом?**
Не включать по умолчанию. Использовать точечно для задач, где нужен отчёт с несколькими источниками, а не быстрый ответ.

## Сегодня

Заведи один проект под самого крупного клиента: инструкции — в поле проекта, последний бриф и отчёт — в базу знаний. Проверь через новый чат внутри проекта, подхватил ли Claude контекст без пересказа.
